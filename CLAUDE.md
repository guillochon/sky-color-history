# Writing conventions

- Use American spelling everywhere: the paper (`latex/`), the site (`model/site_src/`), code comments, identifiers, commit messages and docs. So color, center, meter/kilometer, gray, neighbor, vapor, favor, catalog, labeled, leveling, traveled, aluminum, paleo-, normalize/ionization (-ize, -ization), ocher, story (of a building), metric tons.
- Keep British spellings only where they are part of a proper name or a quoted title: "Yale Bright Star Catalogue", publication titles in `latex/refs.bib`, the HTML attribute `aria-labelledby`, and "Plough" as a search alias for the Big Dipper.
